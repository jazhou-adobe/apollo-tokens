# Command Center Feed: sources behind the decisions

The Feed additions ([briefs/command-center-additions.md](../briefs/command-center-additions.md)) follow the hermes-hub behaviour spec `docs/specs/command-center.md` and the Human's approval of the Hub's static preview (2026-11-20). Where a design decision rests on a standard or a platform rule, it is cited here.

| Decision | Where | Source |
|---|---|---|
| One sticky action bar, with `scroll-padding-block` on the root so focus never sits under the bar or the app bar | [round-widgets.md](../components/round-widgets.md) (Page-scroll Round), [feed-widgets.md](../components/feed-widgets.md) | [WCAG 2.2 SC 2.4.11 Focus Not Obscured (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html); [MDN `scroll-padding`](https://developer.mozilla.org/en-US/docs/Web/CSS/scroll-padding) |
| "Only the bar of the Round in view sticks" needs no script: a sticky box stays inside its containing block | [feed-widgets.md](../components/feed-widgets.md) | [MDN `position: sticky`](https://developer.mozilla.org/en-US/docs/Web/CSS/position#sticky_positioning) |
| Preview frames use `overflow: clip`, which does not make a scroll container, so sticky parts still stick to the page | `preview/hermes-preview.css` | [MDN `overflow`](https://developer.mozilla.org/en-US/docs/Web/CSS/overflow) (`clip` forbids scrolling; `hidden` creates a scroll container) |
| Lock soon warns at 60 s, before the deadline the Human cannot extend | [feed-widgets.md](../components/feed-widgets.md) (Lock soon) | [WCAG 2.2 SC 2.2.1 Timing Adjustable](https://www.w3.org/WAI/WCAG22/Understanding/timing-adjustable.html) (warn at least 20 s ahead) |
| Toasts are not the announcement; one polite status region speaks each event once | [overlays.md](../components/overlays.md) (Toast variants) | [WCAG 2.2 SC 4.1.3 Status Messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html) |
| Toasts under the app bar, out of the flow, so a new Round never moves the Feed | [overlays.md](../components/overlays.md) | hermes-hub spec ("New Rounds append at the end. Focus and scroll position never move") and the Hub's build finding in `web/preview/GAPS.md` |
| Image Attachments require alt text; without it the image is not shown | [round-widgets.md](../components/round-widgets.md) (Image Attachment) | [WCAG 2.2 SC 1.1.1 Non-text Content](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html); [W3C WAI Images tutorial](https://www.w3.org/WAI/tutorials/images/) |
| GIFs offer Play instead of looping under reduced motion | [round-widgets.md](../components/round-widgets.md) | [WCAG 2.2 SC 2.2.2 Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html) |
| Diff folds are disclosures, collapsed by default | [round-widgets.md](../components/round-widgets.md) (Diff) | [APG Disclosure pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) |
| The Lanes drawer is a non-modal `aside`, not a dialog; Dismiss and Redirect are inline panels, not modal dialogs | [agent-widgets.md](../components/agent-widgets.md), [feed-widgets.md](../components/feed-widgets.md) | [APG Dialog (Modal) pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) (modal dialogs make the rest of the page inert, which the lanes and the Round must not be) |
| Fill values under a strict Content-Security-Policy: CSSOM or a `data-fill` scale, never a `style` attribute | [status-widgets.md](../components/status-widgets.md) (Policy timer) | [MDN CSP `style-src`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/style-src) (without `'unsafe-inline'`, inline `style` attributes are blocked; styles set through the CSSOM are not) |
| The In view cue is an SVG chevron plus words, not a triangle glyph | [feed-widgets.md](../components/feed-widgets.md) (Feed index) | This system's contract (no Unicode glyphs as icons, [screen-generation-rules.md](../agent-contract/screen-generation-rules.md)); the glyph is also outside the latin subsets the fonts ship |
